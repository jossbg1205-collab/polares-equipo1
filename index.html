1. Fundamentos del sistema polar

El sistema tiene un origen llamado polo (O) y una semirrecta horizontal hacia la derecha, el eje polar. Un punto P se describe con el par ordenado (r, θ): r es la distancia dirigida desde el polo y θ es el ángulo medido desde el eje polar, positivo en sentido antihorario.

Cómo graficar cuando hay signos negativos

  1. Gira primero. Parte del eje polar y gira θ: antihorario si θ > 0, horario si θ < 0. Así queda fijada una semirrecta.
  2. Avanza |r| unidades sobre esa semirrecta si r > 0.
  3. Si r < 0, avanza |r| unidades sobre la semirrecta opuesta (la que forma θ + 180°). Por eso (−3, 60°) y (3, 240°) son el mismo punto.
  4. Un punto tiene infinitas descripciones: (r, θ) = (r, θ + 360°k) = (−r, θ + 180° + 360°k).

2. El puente Cartesiano ↔ Polar

Superpón los dos sistemas: el polo sobre el origen y el eje polar sobre el eje x positivo. Un punto P con distancia r al origen forma un triángulo rectángulo de hipotenusa r, cateto horizontal x y cateto vertical y.

  1. Del coseno: cos θ = x / r, así que x = r cos θ.
  2. Del seno: sen θ = y / r, así que y = r sen θ.
  3. Eleva al cuadrado y suma: x² + y² = r²cos²θ + r²sen²θ = r²(cos²θ + sen²θ) = r². Entonces r² = x² + y².
  4. Divide la segunda ecuación entre la primera: y / x = sen θ / cos θ, es decir tan θ = y / x (con x ≠ 0).
x = r cos θ    y = r sen θ    r² = x² + y²    tan θ = y/x

Cuidado: arctan(y/x) solo devuelve ángulos entre −90° y 90°. Debes revisar el cuadrante de (x, y) y sumar 180° si está a la izquierda del eje y.

Convertir ecuaciones

x² + y² = 4x → polar
  1. Sustituye x² + y² = r² y x = r cos θ: r² = 4r cos θ.
  2. Divide entre r (el polo sigue incluido, pues r = 0 aparece cuando θ = 90°).
  3. r = 4 cos θ: una circunferencia de radio 2 centrada en (2, 0).
r = 2 sen θ → cartesiano
  1. Multiplica por r para formar términos conocidos: r² = 2r sen θ.
  2. Sustituye: x² + y² = 2y.
  3. Completa cuadrados: x² + (y − 1)² = 1, circunferencia de radio 1 centrada en (0, 1).

4. Aplicación: límites en dos variables

Al acercarse a (0, 0) por caminos distintos, un límite puede dar resultados diferentes. En polares, acercarse al origen es simplemente r → 0, y el ángulo θ describe el camino. Se sustituye x = r cos θ, y = r sen θ; si el resultado tiende al mismo valor sin importar θ, el límite existe.
